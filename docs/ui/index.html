Glisser Déplacement uniquement au-delà de ×1, seuil de 5 px avant de considérer un glisser. La vue reste bornée à la carte : jamais de vide autour. Curseur cursor-grab / cursor-grabbing zoomé, cursor-crosshair à ×1 si un clic a un effet (sélection de joueur, pose de libellé).
Pincer Mobile : deux doigts zooment en continu autour du milieu des doigts (pinchMapZoom), puis le zoom se cale au lâcher sur le palier de ×0,5 le plus proche (snapMapZoom). Le second doigt annule le glissé et le clic du premier ; le doigt resté posé ne glisse ni ne clique. Pointeurs tactiles capturés par le cadre (touch-none : le navigateur ne zoome pas la page). Dans DropZoneMapViewport, donc sur toutes ses cartes (05/10/2026).
Placement Haut-droite (absolute right-3 top-3 z-40) d'un conteneur relative. Le coin haut-gauche est réservé aux informations et bascules propres à la carte (« Périmètres », « Cap C-130 »), avec le même gabarit h-10 rounded border-white/25 bg-slate-950/80 backdrop-blur.

Règles d'Or
  • OBLIGATOIRE : Utiliser <MapZoomControl /> et les fonctions de @/lib/map-zoom. Ne jamais réécrire les boutons de zoom dans une page, ni empiler + / − verticalement.
  • OBLIGATOIRE : Même effet au clic et à la molette (stepMapZoom). Un zoom multiplicatif à la molette et additif aux boutons donne deux cartes qui ne réagissent pas pareil.
  • ATTENTION MOBILE : Conteneur de carte en touch-none pour que le glisser déplace la carte et non la page. Les badges du coin haut-gauche doivent laisser la place au contrôle (max-w-[calc(100%-12rem)]) et masquer leurs détails secondaires sous sm.

Exemple d'Utilisation
import MapZoomControl from '@/components/ui/MapZoomControl'
import { MAP_ZOOM_MIN, clampMapZoom, stepMapZoom, wheelZoomDirection } from '@/lib/map-zoom'

const MAX_ZOOM = 4
const [zoom, setZoom] = useState(MAP_ZOOM_MIN)

// Molette : écouteur natif non passif, un palier par cran, ancré sous le curseur.
useEffect(() => {
  const element = viewportRef.current
  if (!element) return
  function handleWheel(event: WheelEvent) {
    const direction = wheelZoomDirection(event.deltaY)
    if (direction === null) return
    const next = stepMapZoom(zoomRef.current, direction, MAX_ZOOM)
    if (next === zoomRef.current) return   // en butée : la page défile
    event.preventDefault()
    applyZoomAnchoredAt(next, event.clientX, event.clientY)
  }
  element.addEventListener('wheel', handleWheel, { passive: false })
  return () => element.removeEventListener('wheel', handleWheel)
}, [])

return (
  <div className="relative aspect-square overflow-hidden">
    {/* … calques de la carte … */}
    <MapZoomControl
      zoom={zoom}
      max={MAX_ZOOM}
      onZoomChange={(next) => setZoom(clampMapZoom(next, MAX_ZOOM))}
      onReset={() => setZoom(MAP_ZOOM_MIN)}
    />
  </div>
)
